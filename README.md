🔥 DataForge Analytics Dashboard

📌 Overview

DataForge Analytics is an intelligent, enterprise-style data analytics dashboard built using Streamlit.It allows users to upload any CSV/Excel file and instantly generate interactive visualizations, insights, and business intelligence dashboards.This project simulates a real-world BI (Business Intelligence) tool with automated data processing and visualization.

🚀 Key Features

🔍 Smart Data Processing

* Auto-detects numeric & categorical columns
* Handles duplicate column names
* Cleans and standardizes column names
* Detects date columns automatically

 📊 Interactive Dashboard

* KPI Metrics (Total, Growth %, Data Quality)
* Trend Analysis (Line Charts)
* Contribution Analysis (Pie Charts)
* Leaderboard (Top/Bottom performers)

🎛️ Dynamic Filters

* Category filters (auto-generated)
* Numeric range sliders
* Real-time data filtering

📈 Advanced Insights

* Missing value analysis
* Summary statistics
* Column type breakdown
* Sample missing data preview

💾 Export Feature

* Download cleaned & filtered dataset instantly

🛠️ Tech Stack

* Python 🐍
* Streamlit
* Pandas & NumPy
* Plotly (Interactive Charts)
